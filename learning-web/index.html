📖 先理解，再写代码

1. 类型标注 ≠ 自动验证

subject: str 表示期望使用字符串。普通 Python 不会在所有函数调用处自动检查类型；Pydantic 则在创建模型时验证输入。

2. Field 是数据契约

from pydantic import BaseModel, Field

class ReadingSession(BaseModel):
    minutes: int = Field(ge=1, le=180)

意味着读书时长在1至180分钟之间。工单标题也应该限定长度，避免任意内容进入业务系统。

3. 默认转换与严格类型

Pydantic 的 bool 在默认模式下可能把 "yes" 转成 True；Agent 工具参数要用 StrictBool 等明确防止非预期转换。

4. 输入模型和存储模型不同

TicketCreate 只允许客户填写标题和描述。Ticket 额外拥有由系统产生的 ID、创建时间和状态，防止客户端冒充系统字段。
